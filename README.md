
# Image Carousel / Slider

## Description
A responsive image carousel built using HTML5, CSS3, and JavaScript.
It displays multiple images with captions and smooth transitions.

## Features
- Five image slides
- Next and previous buttons
- Automatic slide rotation
- Pause on hover
- Clickable slide indicators
- Responsive design
- Smooth transitions
- Slide counter

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Ensure you have an internet connection for the images.

## Project Structure
image-carousel/
├── index.html

## Learning Outcomes
This project demonstrates DOM manipulation, event handling,
array indexing, setInterval, timer management, and CSS transitions.
